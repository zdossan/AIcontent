# AIcontent - short drama сату боты

Қазақ тіліндегі Telegram бот: қысқа метражды сериалдарды сатады.
Алғашқы бөлімдер тегін, толық нұсқа - Kaspi арқылы төлем, содан кейін
жабық арнаға автоматты қолжетімділік.

Python 3.12 + aiogram 3. Төлем - [Arzan Pay](https://pay.arzan.cloud/docs).

## Орнату

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
cp .env.example .env      # токен мен API кілтті қойыңыз
```

## Іске қосу

```bash
.venv/bin/python -m bot
```

## Тесттер

```bash
.venv/bin/pytest
```

## Ботты алғаш рет баптау

1. @BotFather-тен бот жасап, токенді `.env` файлына қойыңыз.
2. pay.arzan.cloud кабинетінен API кілт алып, `ARZAN_API_KEY`-ге жазыңыз.
3. Өзіңіздің telegram id-іңізді `ADMIN_IDS`-ке қойыңыз.
4. Ботты қосып, оған `/жаңа` деп жазыңыз - сериал туралы сұрақтарға жауап
   бересіз, бот байлау кодын береді.
5. Жабық арна ашыңыз, ботты админ етіп қосыңыз («Пригласить пользователей»
   құқығы міндетті), баптауда «Запретить сохранение контента» қосыңыз.
6. Арнада `/bind КОД` деп жазыңыз.
7. Видеоларды арнаға жүктеңіз. Әр видеоның тақырыбына бөлім нөмірін жазыңыз:
   `1`, `2`, `3` ... Бот оларды өзі жинап алады.
8. `/bolimder` деп тексеріңіз - қай бөлім жетіспейтінін көрсетеді.

> Видеоны арнаға өз аккаунтыңызбен жүктейсіз (шектеу 2 ГБ). Бот оларды тек
> көшіріп жібереді, сондықтан 50 МБ шектеуі әсер етпейді.

## Сервер (Hetzner)

Алғаш рет, серверде root атынан:

```bash
bash deploy/setup.sh
```

Содан кейін әр жаңарту сайын, Mac-тан:

```bash
./deploy/deploy.sh ubuntu@SERVER_IP
```

Логтар: `ssh ubuntu@SERVER_IP 'journalctl -u aicontent-bot -f'`

## Эксплуатация

- **Дерекқор:** `/opt/aicontent-bot/aicontent.db`. Бэкап - файлды көшіру:
  `scp ubuntu@SERVER_IP:/opt/aicontent-bot/aicontent.db ./backup.db`
- **Тест режимінен шығу:** нақты ақша қабылдау үшін `.env`-те
  `ARZAN_SANDBOX=false` қойып, қайта деплой жасаңыз.
- **Сатылымдар:** ботта `/stats` және `/export` (CSV).
- **Қолжетімділік берілмей қалса:** админге автоматты хабарлама келеді,
  қолданушы «🔄 Қайта көру» түймесін басса, бот қайта жасайды.
